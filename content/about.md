## 它是什么

每天从公开信息源里筛出值得看的几条，写成简报：事实、入选理由、判断，以及原文链接。内容按「今日重磅 / AI / 政策 / 市场 / 社会」分节，往期可切换。

## 怎么读

- 每条先看事实，再看「入选理由」和「AI 点评」——后者是判断，不是结论。
- 重要信息请打开原文核对；简报只做压缩，不替代原始来源。
- 页面按日期归档，最新一期是首页，顶部下拉切换往期。

## 边界

- 只做事实提取与判断记录，不构成投资建议。
- 来源链接指向公开报道，版权归原作者。
- 构建只需要 Python 3 标准库，产物是纯静态 HTML / CSS / JS。
