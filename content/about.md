title: 关于这个项目
summary: 一个只用 Python 标准库的静态站点生成器，用来整理每日简报与阅读摘录。
---

## 它做什么

把 Markdown 简报、一份阅读 JSON 和一组手写样式，生成三个页面：首页的最新简报、可切换往期的归档页，以及带时间线 / 按书视图的阅读摘录页。

## 为什么不用框架

- 构建只需要 Python 3，没有 Node 依赖，也没有数据库。
- 产物是纯静态 HTML / CSS / JS，可以放到任意静态托管。
- 数据与展示分离：换掉 content/ 里的示例内容，就能变成你自己的档案。

## 数据边界

仓库里的简报、书名、作者、划线、批注与统计都是示例内容，不对应真实出版物。替换成自己的数据前，请确认你有权公开这些文字；摘录原文的版权归原作者。
